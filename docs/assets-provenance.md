# Asset provenance

All game artwork was generated for this project with the built-in OpenAI ImageGen tool on 2026-10-27. No art, characters, music or code was extracted from another game.

- `docs/concept.png`: complete desktop design concept. Brief: midnight botanical arcade, navy #080e15, mint #c9ff85, lilac #bca6ff, open editorial introduction and live arena; fully native HUD and controls.
- `dist/assets/arena.png`: top-down dark botanical environment. Brief: empty dark center, slate and teal foliage at edges, lavender wisteria, sparse fireflies, no characters/grid/text/UI.
- `dist/assets/sprites.png`: transparent three-column sprite sheet. Brief: ivory-mint wisp, lavender echo, lime four-point collectible; dark eyes, painted glow, separate padded objects, no text. Source rectangles are selected at render time; sprite files are not edited.
- `dist/assets/icon.svg`: original code-native double-circle mark.
- `dist/assets/barlow-condensed.ttf`: Barlow Condensed, downloaded from Google Fonts official static host; distributed under the bundled `FONT-LICENSE.txt` (SIL OFL).
- Sound is synthesized with Web Audio oscillators; there are no downloaded audio samples.
- `docs/gameplay.png` and `dist/assets/social.png`: actual browser screenshots, not fabricated player results.

Code is MIT licensed. Generated artwork is supplied with permission to reuse and modify for this project and its forks to the extent rights are available; this is not a claim of exclusive copyright in AI-generated imagery. The font retains its own OFL license.

UI changes after the concept: the dash-to-shatter mechanic, daily/free modes, pause/result/replay states, local best, Chinese translation, and player-made Boss mode were added for functional requirements. The live renderer, not the mockup, is the gameplay implementation.

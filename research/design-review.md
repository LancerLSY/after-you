# AFTER YOU：玩法评审与第一版规则

评审日期：2026-10-27。范围：直接同类核查、可实现规则、试玩验收。以下数值是待试玩验证的初值，不是已验证的留存结论。

## 结论

保留“自己的动作成为敌人”，把主要动词改为**迎着过去冲刺，把危险击碎得分**。一句话卖点：**你制造每一个敌人，也能亲手击碎它。** 固定 60 秒、每 10 秒产生一个 echo、3 条命，适合立即开玩和录制短视频。首版不放升级选择、长剧情、LLM 实时依赖；先证明移动、击碎、连击足够好玩。

纯躲避版本与现有作品高度接近，不能宣传全球首创。改进应体现在具体手感、主动破局、可复现挑战和分享反馈，而非修改名称。

## 必须解决的风险

| 风险 | 具体修正 |
|---|---|
| 追踪鼠标过于自由，危险显得稀薄 | 角色朝目标移动，限制速度；不能瞬移到光标。冲刺方向在按下时锁定 |
| 幽灵随机追踪让“过去的自己”失去意义 | echo 只重放录制轨迹，不追踪、不额外加速；危险来源可解释 |
| 被打碎的 echo 消失到下一轮后，熟练玩家无事可做 | 打碎后休眠 2 秒再回放，奖励每轮限一次；安全操作仍有价值 |
| 复活、轨迹首尾衔接或冲刺穿模造成冤死 | 复活提前显示；断点不可形成跨场地碰撞线；使用连续碰撞检测 |
| 站着等幽灵刷新即可刷分 | echo 奖励绑定录制片段中的真实收集量；静止生成的空 echo 没有分；同 echo 同周期只结算一次 |
| 前 10 秒没有亮点 | 立即有收集反馈和可用冲刺；第一只 echo 到场时明确显示它复制刚才的动作；首次击碎要在 15 秒内发生 |
| 美术粒子遮挡危险 | 玩家实心、echo 空心、碎片菱形；光晕不计碰撞；减弱动画设置保留全部判定信息 |

## 精确的第一版循环

采用固定逻辑坐标并等比适配屏幕；下面以短边 600 单位为例，尺寸改变时统一缩放。

| 项目 | 初值与规则 |
|---|---|
| 局长 | 60 秒模拟时间；HP 归零提前结束；暂停与后台失焦停止模拟 |
| 移动 | 240 单位/秒；玩家碰撞半径 8；鼠标/拖动设目标；键盘归一化方向，斜向不能更快 |
| 冲刺 | 单次按下触发，0.18 秒，800 单位/秒；距离约 144；冷却 2.4 秒，从触发计时；无多重存储、无击中退款 |
| 冲刺方向 | 朝输入方向；无方向输入时沿最后有效方向；边界截断，不反弹、不穿墙 |
| 冲刺判定 | 全程对 echo 无敌；扫过 echo 核心即击碎；用相对运动的 swept collision，不能只检查帧末重叠 |
| 生命 | 3；普通接触减 1；受伤后 1.25 秒无敌；同一步最多减 1；连击归零；轻微停顿须不改变模拟时钟 |
| echo 生成 | 10/20/30/40/50 秒生成上一段 10 秒轨迹；最多 5 只；录制位置、时间和朝向，不能根据当前帧率推导历史 |
| echo 回放 | 每 10 秒重放自己的片段；速度忠实原轨迹。过去的冲刺以明亮细箭头提前预告；不附带额外伤害倍率 |
| echo 击碎 | 休眠 2 秒；隐藏期间回放时钟继续走，复活到当前应在位置；复活前 0.7 秒显示虚线轮廓，激活后 0.35 秒碰撞宽限 |
| echo 首尾断点 | 首尾不连接为碰撞线；循环重置显示起点预告并给予同样宽限；所有新 echo 也适用 |
| 可视轨迹 | 显示未来约 0.7 秒的细线预告；其余路径极淡。只有实体核心有伤害，线条不伤人 |

输入优先级须固定：**读取输入/开始冲刺 → 更新位置 → 冲刺击碎 → 普通伤害 → 收集 → 计分 → 结束判定**。若在第 60 秒恰好收集或击碎，只结算时间戳严格小于结束时刻的事件。快进调试不能进入正式记录。

移动端建议右手大拇指拖动移动、左下 64px 冲刺按钮；键盘为 WASD/方向键 + Space，鼠标为移动 + 点击。UI 要显示该设备实际操作，不能让玩家靠猜发现冲刺。

## 收集、公平性与防刷分

碎片位置和出现时刻由 `seed + rulesVersion` 提前生成，所有同种子玩家拿到相同时间表。不要因玩家站位或幽灵位置临时重抽位置，否则“同一个挑战”实际不同。

建议起始 3 枚，此后每 1.5 秒出现 1 枚；每枚出现前 0.5 秒预告、存在 6 秒、同屏最多 5 枚。候选锚点离边界至少 40，连续锚点相距至少 150，10 秒内不重复同一锚点；同一个静止位置不能持续产分。所有选择在生成时间表时完成，不能依据玩家行为调整。碎片可落在危险路线附近，因为冲刺能解决风险；不生成在 UI 遮挡区。

每枚碎片固定 **20 分**。为每个 echo 保存其录制片段内的收集量 `N`：

```text
echoBase = N == 0 ? 0 : 50 + 10 × min(N, 8)
eligible = 当前 10 秒周期内，该 echo 尚未给分，且 echoBase > 0
multiplier = 1 + 0.5 × min(此前连续 eligible 击碎次数, 4)
本次得分 = round(echoBase × multiplier)
```

连续两次有效击碎间隔不得超过 3.2 秒；超时或受伤清零；同一次冲刺穿过多个 echo 按碰撞时间先后结算，最大 ×3。重复打碎同一 echo 可以保命，但不会给分、续连击或刷新奖励。每次新 10 秒周期清除各 echo 的“已给分”标记。没有存活时长分和剩余生命加分，避免站在角落比主动行动更有效。空 echo 用更暗的颜色显示，文案提示“收集的光，决定过去的价值”。

该方案不是绝对防作弊系统：它抑制的是合法输入下的无聊刷分。客户端总分、摘要或哈希本身不能证明成绩真实。首版只做本地最佳与可复现挑战；若上线公共榜，需保存输入并在可信端重放验证，未验证记录不得冒充世界纪录。

## 教程与结果页

首次进入只有“开始 60 秒”和一句操作提示。局内按条件显示并自动收起：

1. 0–3 秒：“移动，收集光。”第一个碎片易达，收集立即有音高递增和短脉冲。
2. 第一次可冲刺时：“点击 / Space：冲刺。”按钮持续显示冷却环，不弹模态框。
3. 10 秒：“这是 10 秒前的你。”新 echo 用瞬时连线连接其源片段，再恢复正常。
4. 第一次 echo 靠近且冲刺可用：“冲过去，击碎它。”首次击碎显示明确的 `BREAK +分数`。
5. 第一次受伤：“普通碰撞会受伤，冲刺时安全。”仅提示一次；不停止可控性。

教程不暂停正式局、不修改难度；另设练习入口供需要慢速学习的人使用。结果页优先级：**分数 / 最长连击 / 击碎数 → 再来一次 → 挑战朋友**。显示致命 echo 来自第几段；可用最后 3 秒淡色回放解释失败，但不阻止重开。按重开到重新可控应低于 1 秒。

## 分享规则

每日挑战采用固定 UTC 日期和规则版本；所有玩家同日同种子，显示明确日期及重置时间。练习与每日成绩分开。分享链接含 `seed`、`rulesVersion` 和可选目标分；读取到陌生版本应提示版本不一致，不能悄悄用新规则比较。

卡片推荐：`AFTER YOU · 2026-10-27 / 1,840 分 / 12 次击碎 / 最高 ×2.5 / 60 秒，超越这个分数。` 同时提供系统分享、复制文字链接、保存图片，不要求登录。没有真实分布时不显示“击败 99% 玩家”。用户点击分享才执行分享；不能自动发到任何社交账号。

更有潜力的第二天功能是**“把我的轨迹发给朋友”**：共享实际录制的 2–3 段轨迹，变成朋友可玩的 30 秒挑战。这比只有截图更能体现本游戏的独特性；实现前需解决轨迹大小、版本和有效性，不能拖延第一版手感。

## 试玩与退出门槛

至少找 6 名没看过设计的人，3 人手机、3 人桌面，各自由玩 3 局；观察员不解释规则。记录 `start / first_collect / first_dash / first_break / hit / death / finish / restart / share_intent`，按场次关联，不采集身份信息。开发者和自动化测试不能冒充这组真人样本。

| 检查 | 首轮通过门槛 |
|---|---|
| 可理解 | ≥5/6 在 5 秒内移动并收集；≥4/6 在 15 秒内完成第一次击碎 |
| 主题成立 | ≥5/6 能自己说出“敌人在重复我刚才的路线” |
| 愿意重玩 | ≥4/6 在未被要求时主动开始第二局；记录实际行为，不问诱导性问题 |
| 技巧成长 | ≥4/6 到第三局能说出并尝试一种策略：留冲刺、规划路径、聚集 echo 或选择收集顺序 |
| 公平 | ≥5/6 能解释一次受伤原因；复活/循环断点/输入延迟导致的不明伤害必须为 0 |
| 难度 | 首局多数能活过 25 秒；第三局约一半以上能完成 60 秒，之后靠分数继续追求成长 |
| 分享可用 | ≥5/6 不需提示找到挑战朋友入口；实际外部发布须由玩家主动完成 |

必跑的机械测试：同输入在 30/60/120Hz 下同成绩；单帧穿过 echo 必须命中；边界冲刺不会移出场地；静止 60 秒不会取得有效击碎分；重复击碎不重复奖励；受伤无敌期间不连扣命；后台恢复不会补算死亡；同 seed 同版本的碎片时间表完全一致；触摸滑动不滚动页面；关闭动画和静音仍可理解危险。

若 6 人中不到 4 人自发重玩，先修第一击碎反馈、运动和失败可解释性，暂缓增加内容及宣传。若自发重玩通过但没人愿意发挑战，再做可玩的轨迹分享。10k stars 是外部结果，不可用玩法评审或内部测试代替实际验证。
